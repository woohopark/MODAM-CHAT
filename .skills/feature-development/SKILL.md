# Orbit 요구사항·기능 작업

## 적용 조건

이 저장소의 요구사항/문서 정리, 기능 추가·수정·복구, AGI 어댑터 연결에 적용합니다. 다른 프로젝트나 AGI 서버 운영에는 적용하지 않습니다. 사용자 지시를 우선합니다.

## 입력과 사전 확인

prd.md, AGENTS.md, Agent.md, skill.md, 관련 docs/소스/테스트와 git 상태를 읽습니다. 작업을 관련 FR/NFR ID에 연결합니다. API 작업은 docs/AGI_INTEGRATION.md의 미확정 계약부터 확인합니다.

## 문서 작업 경로

1. 현재 구현/검증/배포 상태를 확인합니다.
2. PRD의 요구사항·수용 조건·현황·향후 후보를 구분합니다.
3. 에이전트 책임, 스킬 순서, 배포/패키지 문서를 실제 상태에 맞게 연결합니다.
4. 포맷/상대 링크/명령·경로·상태의 정합성을 검사합니다.
5. 이전 검증 기록은 이전 결과로 유지하고 이번 문서 검사와 구분합니다.

## 기능 작업 경로

1. 요구사항 ID와 변경 영향을 확인합니다.
2. domain/application/providers/ui 중 맞는 책임에서 변경합니다.
3. 제공자 확장은 ChatProvider 구현과 main.ts 조립으로 제한합니다.
4. 관련 정상·실패·취소·동시성 테스트를 추가합니다.
5. 기능/API/패키지 계약 변경 시 PRD와 관련 docs를 갱신합니다.

## 검증

문서만 변경하면 npm run format 및 npm run format:check와 링크 검사를 수행합니다. 코드/의존성이 변경되면 npm run check까지 실행합니다. UI는 가능하면 실브라우저 모바일/데스크톱/IME를 확인합니다. 못한 검증은 보고에 명시합니다. 실패는 원인 수정 후 해당 검사를 재실행합니다.

## 배포와 완료 보고

현재 사용자 요청과 호스팅 정책에 따라 배포합니다. 문서 전용 작업에 새 서비스 배포를 만들어야 한다고 가정하지 않습니다. URL은 성공한 배포/현재 사이트 상태에서 확인합니다. 변경 요약, 요구사항 연결, 문서 링크, 검사 결과, 미검증/미결정 항목을 전달합니다. 토큰·비밀 값은 파일과 출력에 남기지 않습니다.

## 테마 변경 검증 — FR-11

라이트/다크 양방향 전환, 버튼 접근성 상태/이름, 아이콘, 새 대화에서의 테마 유지, 문서의 저장 범위를 함께 확인합니다. 자동 저장이나 OS 테마 연동을 임의로 추가하지 않습니다. DOM 검사와 실브라우저 대비/레이아웃 검증을 구분합니다.

## 실제 AGI 연동 — FR-03/04/06/07/13~16

승인 범위는 로그인·서버 대화 저장·멀티턴·삭제·영속 실행이다. [API 계약](../../docs/AGI_INTEGRATION.md)과 [배포](../../docs/DEPLOYMENT.md)를 따른다. domain/application/providers/ui와 server(BFF)를 분리한다. 제공자 이벤트는 ID·상태·최종 답변을 전달하고 ConversationRepository는 복원/삭제를 담당한다. 기존 문자열 데모 제공자는 명시적인 데모 빌드에서만 쓴다. 새 서버/제공자 경계를 성공·오류·취소·재구독·권한 테스트로 검증하며 다크/한국어 입력 회귀를 유지한다. Git/클라이언트/로그에 세션/Groq 비밀을 넣지 않는다. loopback 실행을 외부 운영 배포로 보고하지 않는다.
