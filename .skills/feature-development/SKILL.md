# 기능 개발

## 적용 조건

이 저장소 기능 추가·수정·복구에 적용합니다. AGI 서버 운영이나 다른 프로젝트 배포에는 적용하지 않습니다.

## 입력 및 사전 확인

사용자 요구, AGENTS.md, 관련 docs/소스/테스트를 읽습니다. API 변경은 docs/AGI_INTEGRATION.md를 읽고 미확정 계약을 실제 구현으로 취급하지 않습니다.

## 작업 순서

1. 바뀌는 동작과 영향을 파악합니다.
2. domain/application/providers/ui 중 책임이 맞는 위치를 선택합니다.
3. 제공자 확장은 ChatProvider 구현과 조립 지점으로 제한합니다.
4. 관련 정상·실패·취소·동시성 테스트를 추가합니다.
5. 기능/계약/패키지가 바뀌면 Markdown을 갱신합니다.

## 검증

npm run format, npm run check를 실행합니다. UI는 가능한 경우 실제 브라우저에서 모바일·데스크톱·키보드·한글 IME를 확인합니다. 못한 검증은 보고에 명시하고 실패는 수정 후 관련 검사를 재실행합니다.

## 완료 보고

바뀐 동작, 테스트 결과, 문서 위치, 남은 제한을 간단히 보고합니다. API 키·대화·토큰을 출력하거나 Git에 남기지 않습니다.
