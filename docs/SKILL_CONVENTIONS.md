# 스킬 Markdown 컨벤션

저장소 스킬은 `.skills/<kebab-case-name>/SKILL.md`에 둡니다. 플랫폼 전역 설치/자동 검색과 별개이며 AGENTS.md에서 명시적으로 읽도록 연결합니다.

```md
---
name: feature-development
description: Orbit 기능 수정·테스트·문서 갱신 작업 절차.
---

# 기능 개발

## 적용 조건

## 입력 및 사전 확인

## 작업 순서

## 검증

## 완료 보고
```

name은 폴더명과 일치하며 description은 적용 시점을 설명합니다. 포함/제외 범위, 실제 명령, 결과물, 완료 조건을 명시합니다. 가짜 경로·추측한 환경·인증 토큰을 넣지 않습니다. 공통 규칙은 docs로 연결하고 복제하지 않습니다.

사용자 요구와 저장소 지침을 우선합니다. 기존 기능을 읽고 맞는 책임 계층에서 변경합니다. 요청 없는 기능·패키지·권한·저장을 추가하지 않습니다. 보고에는 수행한 검사와 미수행 검증을 구분합니다.

명령/구조 변경 시 스킬도 갱신합니다. 한 스킬은 한 작업 흐름만 담당하며 반복 사용이 없는 절차를 과도하게 분리하지 않습니다.
