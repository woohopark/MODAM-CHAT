## 화면 시나리오

1. 실제 계정 로그인·Cloud 동의 후 기업 자료 조회를 선택하고 새 대화를 만든다.
2. poc-warehouse/inventory:B:C 질문으로 규정·108개 재고·관련 경로의 근거를 확인한다.
3. 100개 출고 가정에 대해 새 규정 근거와 잔여 8/보충 제안 42를 확인한다. 이 신규 규정·계산 검증은 후속이다.
4. 후속 대명사는 올바른 객체를 참조하거나 확인 질문한다. 새 질문은 과거 재고를 최신 값으로 재사용하지 않는다.
5. 새로고침·로그아웃/로그인·서비스 재시작 후 본인 이력을 복원한다.
6. ACL 회수 후 복원/SSE/실행 조회에서 기업 답변이 숨겨지는지 확인한다.
7. 단절 후 같은 run 재구독, 취소 후 늦은 이벤트 무시, 중복 요청 처리·삭제 충돌을 확인한다.
8. 다른 계정의 대화/실행 접근, 서비스 중단, 오래된 자료에서 노출/허위 성공이 없는지 확인한다.
9. 라이트/다크·모바일·키보드/포커스·200% 확대·대비·물리 한글 IME를 검증한다.
